<p>&emsp;&emsp;嗨，你好，我是catking01。一名研究型系统工程师（Research Systems Engineer），致力于将物理严格性、数值科学与软件架构统一为可演化的科研基础设施。</p>

<p>&emsp;&emsp;我相信代码是认知的载体，模拟不是黑箱——它是每一步都必须可追溯、可审计、可复现的因果系统。</p>
